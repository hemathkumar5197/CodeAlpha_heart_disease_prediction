# Heart Disease Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on predicting the presence of heart disease using machine learning techniques. It aims to analyze patient health-related features and build classification models to identify potential heart disease cases.

## 🎯 Objectives
- Analyze heart disease data.
- Perform data cleaning and preprocessing.
- Explore relationships between health features and the target variable.
- Train machine learning classification models.
- Evaluate and compare model performance.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Algorithms
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## 📊 Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## ⚙️ Project Workflow
1. Load and explore the dataset.
2. Check missing values and data types.
3. Perform data cleaning and preprocessing.
4. Conduct exploratory data analysis and visualization.
5. Split the dataset into training and testing sets.
6. Train classification models.
7. Compare models using evaluation metrics.
8. Analyze feature importance where supported.

## 📁 Project Files
- `Heart_Diseas.csv` — Dataset used for analysis and model training.
- `heart_disease_prediction.ipynb` — Jupyter Notebook containing the project code (if included).
